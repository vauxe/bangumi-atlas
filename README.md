# Bangumi 星图

[在线体验](https://vauxe.github.io/bangumi-atlas/)

基于 [bangumi/Archive](https://github.com/bangumi/Archive) 每周快照生成的 3D
关系探索器，用于搜索作品、人物与角色，查看详情，并沿它们之间的关系继续探索。
站点无需安装或登录，查询直接在浏览器中执行。

## 可以做什么

- 按名称、别名、正文、字段或关系查找作品、人物和角色，并对结果排序或统计。
- 查看条目的概览、关联与资料；作品还可浏览分集和单集介绍。
- 沿关联跳转到其他节点，或固定多个节点，在星图中保留各自的一跳关系。
- 地址栏会同步当前视角、选中节点和查询状态，复制 URL 即可分享；固定节点只在
  当前会话保留。

## 基本操作

| 操作 | 结果 |
|---|---|
| 点击左上角“搜索与查询” | 输入名称，或添加筛选、关联、正文和排序条件 |
| 左键拖动 / 右键拖动 / 滚轮 | 平移 / 旋转 / 缩放星图 |
| 单击节点或关联条目 | 打开详情，或沿关系移动到新节点 |
| 点击详情顶部的图钉 | 固定当前节点及其一跳关系；固定节点管理器可回看或移除 |
| 单击空白处或按 `Esc` | 取消当前选择，不会清除已固定节点 |
| 点击骰子 | 随机前往一个已加载的节点 |
