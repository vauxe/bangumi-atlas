# bangumi-atlas 探索应用设计文档(桌面端 3D)

把图数据库做成可公开部署的 3D 交互式星图("Bangumi 星图")。
状态:设计定稿,未实施。前置:构建管道(见 [DESIGN.md](DESIGN.md))。
2026-07-31 目标改写:桌面端专属、3D 呈现。

## 1. 目标

- 受众:**桌面浏览器 + 近五年 GPU**(独显或近代集显;
  Apple Silicon Mac 在列,且为基准设备——spike 与验收在其上实测;
  Retina 下必要时钳 devicePixelRatio)
- 3D 呈现 268 万节点全图,线上零服务器,成本不随用户数增长
- 非目标:移动端、低端设备、实时数据、让用户写查询

延迟预算(验收标准,桌面宽带前提):

| 交互 | 预算 |
|---|---|
| 首屏可交互(骨架包) | < 5s |
| 全量几何后台补齐 | < 30s,不阻塞交互 |
| 探索循环(点击 → 邻居亮起) | < 300ms |
| 搜索联想 | < 100ms |
| 全图帧率 | ≥ 30fps |

## 2. 核心架构:客户端 3D 渲染 + 静态数据

工作集/语境二分不变(用户与嵌在语境中的几十个节点交互),
变的是语境层的实现:预烤瓦片 → **客户端 WebGL 直渲全量几何**。
成立前提是目标改写——设备地板固定为桌面 GPU 后,
"发几何给客户端"从缺陷变成可行,且换来栅格方案给不了的能力
(动态过滤、实时重着色、真 3D)。

```
离线(每周,GitHub Actions cron)
  fetch_dump → build_db → verify_db
    ──ForceAtlas2 3D──> 布局坐标(上周坐标热启动)
    ──导出──> 几何包(骨架包+补全分块)、邻接/详情/搜索分片、标签数据
    ──deploy-pages──> GitHub Pages(纯静态,零服务器)
线上
  deck.gl:PointCloud(全量节点)+ LineLayer(骨架边)+ 叠加层(工作集)
  搜索/邻居/详情走静态分片,拾取走 GPU picking
```

数据分层加载:

| 包 | 内容 | 体积(gzip 估) | 时机 |
|---|---|---|---|
| 骨架包 | top ~30 万节点 + 高权重骨架边 | ~10MB | 首屏 |
| 补全分块 | 其余节点坐标/类型(量化 u16) | ~50MB | 后台流式 |
| 分片 | 邻接/详情(summary 全文)/搜索索引 | ~280MB 总库 | 按需 fetch |

站点总体积 ~360MB(无瓦片后反而低于 1GB 预算,余量变大)。

## 3. 交互设计

四层结构不变:搜索着陆 → 总览 → 点击生长 → 领域钩子。3D 适配:

- **相机**:turntable 模式(禁 roll,永不倒置);双击节点 = 聚焦飞行;
  Home 键复位;**俯视 + 正交投影 = 免费的"2D 模式"**(一个视角预设,
  零额外工程,保底可读性)
- **拾取**:GPU picking;重叠节点连续点击循环切换
- **工作集聚光**(遮挡的主解法):选中时语境层亮度降至 ~15%,
  工作集高亮——3D 毛线团瞬间变成"黑暗中亮起的一串灯"
- **深度线索**:雾衰减(远=暗)表达深度;节点大小用**屏幕空间尺寸**
  编码重要性,不随透视缩放,避免"远处的大节点看着像近处的小节点"
- **标签**:billboard 精灵 + 屏幕空间碰撞剔除 + 距离 LOD
- **动态能力(客户端渲染的红利)**:时间机器 = 任意日期范围实时过滤;
  图层切换 = 实时重着色;媒介 chips = 实时调暗——全部零预烤

反模式:让用户写 Cypher;无界展开(永远 top-K + "还有 N 个");
NSFW 进默认视图。(旧清单中的"默认 3D"已随目标改写作废。)
URL 即状态(编码相机位姿 + 选中节点),可分享可收藏。

## 4. 组件明细

- **布局**:igraph ForceAtlas2 输出 3D 坐标;跨周热启动
  (坐标从上次发布站点拉回,`actions/cache` 后备)不变
- **几何包**:坐标量化 u16 + 类型/大小打包(~8B/节点);
  骨架边按权重 top-N(u32 端点对)
- **邻居展开 / 详情 / 搜索**:静态分片方案原样继承
  (邻接 id 分桶、summary 全文、minisearch 前缀分片);
  infobox 仍不上站(未解析 wiki 源码)
- **拾取**:GPU picking 取代空间索引文件
- **标签**:全局 top-K 列表(客户端做剔除),取代 per-tile 标签

## 5. UI 设计

布局:画布全幅,一切浮于其上。冷启动 = 居中搜索框 + 随机传送,
背景缓慢自转的星图;常规态 = 搜索停靠左上、右侧 420px 详情抽屉、
左下图例、右下工具簇(图层/时间/俯视/骰子)。

详情面板:标题 → 类型徽章 + 评分收藏 → summary 折叠 →
关系分组列表(组头 = 解码关系名,组内 = 可点节点 chips,
点击即行走)→ "展开全部 N 个" → bgm.tv 外链。

输入语法:

| 输入 | 反馈 | 预算 |
|---|---|---|
| 左键拖 / 滚轮 | 平移 / 推拉 | ≥30fps |
| 右键拖 | 轨道旋转(turntable,禁 roll) | ≥30fps |
| `2` / `H` | 俯视正交预设 / 相机复位 | 即时 |
| 悬停节点/边 | tooltip(名字+类型 / 解码关系名) | 即时 |
| 单击节点 | 选中:聚光 + 抽屉 + 邻居 top-50 亮起 | <300ms |
| 重叠处连续单击 | 循环切换候选节点 | 即时 |
| 双击节点 | 聚焦飞行 | 400ms |
| 单击空白 | 取消选中,语境层复亮 | 即时 |
| 点抽屉内 chip | 行走:选中转移 + flyTo,历史入栈 | <300ms |
| `/` → 输入 → 回车 | 聚焦 → 联想 → flyTo + 选中 | <100ms 联想 |
| Esc / 浏览器后退 | 逐级退出 / 回上一视图状态 | 即时 |
| 🎲 / 找路径 / 时间滑块 / 图层 chips | 随机传送 / 六度链高亮 / 实时日期过滤 / 实时重着色 | ≤1s |

两条贯穿规则:每个操作可逆(探索无死路);每个状态可分享。

颜色不变(深色表面,校验器验证):作品 `#3987e5` / 人物 `#d95926` /
角色 `#199e70`;媒介层 chips 隔离;社区层格式塔例外;
文字用文本色阶;大小 = log(collects)(屏幕空间)。
动效仅三:flyTo 400ms、邻居 30ms 级联淡入、选中光环单脉冲,
尊重 prefers-reduced-motion;键盘流;颜色永不孤行。

## 6. 取舍记录

- **放弃移动端与低端设备**:目标改写(2026-07-31),换取真 3D 与动态样式
- **3D 可读性代价已知,靠四件套缓解**:工作集聚光、屏幕空间尺寸、
  雾深度线索、俯视正交保底——研究共识(屏幕 3D 分析效率低于 2D)
  仍然成立,缓解不是消除
- **布局冻结 + 热启动**:心智地图与可分享 URL 的前提,不变
- **骨架先行**:首屏只有 top 节点,后台补全——首值时间与全量之间的折中。
  标准化替代品是 OGC 3D Tiles(ADD 细化 = 同样的重要性 LOD 语义,
  deck.gl Tile3DLayer 直接消费,py3dtiles 生成);当前 268 万点全量
  仅 ~43MB GPU 内存,手搓分块够用,规模 ×10 或首屏要压进 2s 时再升级。
  注意 3D Tiles 是"LOD 几何流式"而非预渲染像素,救传输不救 GPU 地板
- **NSFW**:默认过滤,显式开关

## 7. 部署

GitHub Actions cron + Pages artifact 直发,机制不变(零 commit、
零服务器)。站点 ~360MB,余量充足;无瓦片后烤制耗时下降。
runner 约束与逃生舱不变(self-hosted / Cloudflare)。

## 8. 实施顺序(依赖链)

1. **帧率 spike**(新第一验证项):268 万点 + 骨架边灌进 deck.gl,
   实测集显帧率——本方案的成立前提,半天出结论
2. 3D 布局脚本(RELATES_TO 子图验证质量 → 全图)
3. 几何包导出 + 场景渲染 + 聚光/拾取
4. 搜索 + flyTo + 详情抽屉(分片复用)
5. 标签剔除系统
6. 每周 Actions workflow
7. 钩子:时间滑块 → 路径 → 骰子
